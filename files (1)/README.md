# Sports Predictor (Tennis first, Cricket next)

Run locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy free: push these 5 files to a GitHub repo, then at share.streamlit.io choose
"New app", select the repo, main file = app.py. You get a public link.
